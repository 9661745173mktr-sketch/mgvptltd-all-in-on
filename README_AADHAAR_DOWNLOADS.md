# Aadhaar Correction Software Downloads

The Aadhaar Correction section now has direct-download buttons.

Default files expected in `frontend/public/downloads/`:
- `Remote-VPN-Software.zip`
- `VHUI64-Software.zip`

Place the authorized software packages supplied by your software/provider in those exact paths before deployment. The portal does not contain fabricated installer files.

If you prefer external download URLs, set:
- `NEXT_PUBLIC_REMOTE_VPN_LINK`
- `NEXT_PUBLIC_VHUI64_LINK`
